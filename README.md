# SOULHUB — AI-Based Psychological Consultation System

## About the Project

SOULHUB is an AI-based psychological consultation system developed to support users through diary-based emotion prediction and online psychological consultation.

The system uses Natural Language Processing (NLP) to analyze users' daily diary entries and predict emotions, helping connect users with psychological consultation services.

## Features

* **Emotion Prediction:** Analyze daily diary entries using NLP.
* **Online Psychological Consultation:** Support communication between users and psychologists.
* **Appointment Scheduling:** Help users arrange consultations.
* **Psychologist Management:** Provide management features for psychologists.
* **Feedback System:** Allow users to submit feedback.

## Technologies Used

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript
* **Database:** MySQL
* **NLP:** Natural Language Processing
* **Mobile Application:** Flutter

## Project Modules

* **Admin:** Manage the system and psychologist verification.
* **User:** Submit diary entries and access consultation services.
* **Psychologist:** Manage availability and consultations.

## Project Objective

To combine emotion prediction using NLP with online psychological consultation, making consultation services more accessible to users.
